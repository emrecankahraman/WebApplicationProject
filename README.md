Our aim in this project is to raise awareness on cyber security.This is a school project.
In this project, we created Netflix, Spotify, Facebook login screens and wanted to track the user's data by sending them to the user as an e-mail.
We send a unique e-mail to each user in bulk and track whether the user clicks on this e-mail or not, whether the user enters their information in this e-mail, and present this information on the dashboard screen.


# Dashboard
After logging into the system, we can see the data in the dashboard, we can see how many emails were sent, on which dates they were sent, how many of the emails sent were spotify, how many of them were facebook, how many of them were netflix, and how many of them had a success rate.

# Sending Email
If you enter the sent email page on the dashboard, this page welcomes us.If you click on get mail, it reads the emails from a previously existing file and saves them to the database.In the StartId section, it asks from which id value from the database to start and up to which id we want to send mail.With Attack Type, we can decide which page type and send the mail by saying Gönder.
